# โจทย์ฝึกเขียนโปรแกรมภาษา C: เรื่อง String และ Struct (ระดับเบื้องต้น)

---

## ส่วนที่ 1: โจทย์เรื่อง String (สตริง / ข้อความ)

### โจทย์ที่ 1: นับความยาวสตริงด้วยตนเอง (Manual String Length)
* **คำอธิบาย:** สตริงในภาษา C จะปิดท้ายด้วยตัวอักษร Null Terminator (`'\0'`) เสมอ ให้เขียนโปรแกรมเพื่อใช้วงลูปนับจำนวนตัวอักษรทั้งหมดในสตริงโดยไม่ใช้ฟังก์ชันสำเร็จรูป
* **เงื่อนไข:** 
  * **ห้ามใช้** ฟังก์ชัน `strlen()` จากไลบรารี `<string.h>`
  * รับข้อความเข้ามา 1 คำ (ไม่มีช่องว่าง)
* **ตัวอย่างการทำงาน:**
  ```text
  Enter a word: Programming
  Length of the string: 11
  ```

---

### โจทย์ที่ 2: นับจำนวนสระ (Count Vowels)
* **คำอธิบาย:** ตรวจสอบและนับจำนวนสระภาษาอังกฤษที่ปรากฏในข้อความ
* **เงื่อนไข:**
  * นับทั้งสระตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ (`a`, `e`, `i`, `o`, `u`, `A`, `E`, `I`, `O`, `U`)
  * สามารถรับข้อความที่มีช่องว่างได้ (แนะนำให้ใช้ `fgets`)
* **ตัวอย่างการทำงาน:**
  ```text
  Enter a sentence: Hello World
  Number of vowels: 3
  ```

---

### โจทย์ที่ 3: สลับตัวพิมพ์เล็กและพิมพ์ใหญ่ (Toggle Case)
* **คำอธิบาย:** เปลี่ยนแปลงรูปแบบตัวอักษรในข้อความ โดยสลับจากตัวพิมพ์เล็กเป็นพิมพ์ใหญ่ และจากพิมพ์ใหญ่เป็นพิมพ์เล็ก
* **เงื่อนไข:**
  * ตัวอักษรที่ไม่ใช่ภาษาอังกฤษ (เช่น ตัวเลข, ช่องว่าง, เครื่องหมาย) ให้คงไว้ตามเดิม
* **ตัวอย่างการทำงาน:**
  ```text
  Enter text: C Programming 101
  Toggled text: c pROGRAMMING 101
  ```

---

### โจทย์ที่ 4: ตรวจสอบคำพาลินโดรม (Palindrome Check)
* **คำอธิบาย:** คำพาลินโดรมคือคำที่อ่านจากหน้าไปหลัง หรืออ่านจากหลังมาหน้าแล้วได้คำเดียวกัน (เช่น `radar`, `level`)
* **เงื่อนไข:**
  * รับคำภาษาอังกฤษตัวพิมพ์เล็ก 1 คำ (ไม่มีช่องว่าง)
  * แสดงผลลัพธ์ว่าคำนั้นเป็นพาลินโดรมหรือไม่
* **ตัวอย่างการทำงาน:**
  ```text
  Enter a word: radar
  Result: 'radar' is a palindrome.

  Enter a word: hello
  Result: 'hello' is not a palindrome.
  ```

## ส่วนที่ 2: โจทย์เรื่อง Struct (โครงสร้างข้อมูล)

### โจทย์ที่ 1: ระบบบันทึกและแสดงผลข้อมูลนักเรียน (Basic Student Info)
* **คำอธิบาย:** ฝึกการสร้างและใช้งาน `struct` พื้นฐานเพื่อเก็บข้อมูลที่มีหลายชนิดในตัวแปรเดียว
* **เงื่อนไข:**
  * นิยาม `struct Student` ประกอบด้วย:
    * `id` (จำนวนเต็ม - รหัสนักเรียน)
    * `name` (ข้อความ - ชื่อนักเรียน)
    * `gpa` (ทศนิยม - เกรดเฉลี่ย)
  * รับค่าข้อมูลนักเรียน 1 คนจากผู้ใช้ แล้วแสดงผลลัพธ์กลับมาในรูปแบบที่จัดไว้อย่างสวยงาม
* **ตัวอย่างการทำงาน:**
  ```text
  === Input Student Data ===
  Enter ID: 1001
  Enter Name: Somchai
  Enter GPA: 3.75

  === Student Information ===
  ID: 1001
  Name: Somchai
  GPA: 3.75
  ```

---

### โจทย์ที่ 2: หาตำแหน่งของจุด 2D ที่อยู่ใกล้จุดกำเนิดที่สุด (Distance from Origin)
* **คำอธิบาย:** คำนวณหาระยะทางของพิกัด $2D$ จากจุด $(0,0)$ โดยใช้สูตร $d = \sqrt{x^2 + y^2}$
* **เงื่อนไข:**
  * นิยาม `struct Point` ประกอบด้วย `x` (float) และ `y` (float)
  * รับพิกัดของจุด 2 จุด (Point A และ Point B)
  * คำนวณระยะทางจากจุดกำเนิด $(0,0)$ และบอกว่าจุดใดอยู่ใกล้จุดกำเนิดมากกว่ากัน (ใช้ `<math.h>` คำนวณ `sqrt`)
* **ตัวอย่างการทำงาน:**
  ```text
  Enter Point A (x y): 3.0 4.0
  Enter Point B (x y): 1.0 1.0

  Point A distance: 5.00
  Point B distance: 1.41
  Result: Point B is closer to origin.
  ```

---

### โจทย์ที่ 3: ระบบจัดการคลังสินค้าอย่างง่าย (Inventory Array of Structs)
* **คำอธิบาย:** ฝึกการใช้ อาเรย์ของโครงสร้างข้อมูล (Array of Structs) และการหาค่าสูงสุด
* **เงื่อนไข:**
  * นิยาม `struct Product` ประกอบด้วย:
    * `id` (จำนวนเต็ม)
    * `name` (ข้อความ)
    * `price` (ทศนิยม)
  * รับข้อมูลสินค้าทั้งหมด 3 ชิ้น
  * แสดงรายการสินค้าทั้งหมด และค้นหาสินค้าที่มีราคาสูงที่สุด
* **ตัวอย่างการทำงาน:**
  ```text
  === Enter Details for 3 Products ===
  Product 1:
    ID: 101
    Name: Mouse
    Price: 450.00
  Product 2:
    ID: 102
    Name: Keyboard
    Price: 1250.50
  Product 3:
    ID: 103
    Name: Monitor
    Price: 4500.00

  === Most Expensive Product ===
  ID: 103 | Name: Monitor | Price: 4500.00 THB
  ```
